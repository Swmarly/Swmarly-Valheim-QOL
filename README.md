# Swmarly-Valheim-QOL
A collection of quality-of-life fixes for Valheim 1.0, packaged as one BepInEx plugin.

The user-facing feature list and installation instructions are in [`thunderstore/README.md`](thunderstore/README.md). The maintainer/agent hand-off guide is [`DEVELOPMENT.md`](DEVELOPMENT.md); read it before changing Harmony patches, inventory transactions, or server/client behavior.

The repository is intentionally maintained as a single consolidated `main` branch. Build and package with the workflow in `.github/workflows/build.yml` and `scripts/package.py`.
